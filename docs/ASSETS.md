### Regenerating the music
The music is generated by `tools/audio/make_music.py` (numpy and ffmpeg only): plucked oud strings by Karplus-Strong physical modelling, a Hijaz-maqam melody and bass line, a darbuka maqsum rhythm, a soft drone and convolution reverb. It makes three files in `public/assets/audio/`: `ambient.mp3` (60 s, loops seamlessly), `order_complete.mp3` and `level_up.mp3`.

```bash
python3 tools/audio/make_music.py public/assets/audio
python3 tools/audio/verify_music.py public/assets/audio   # tuning, duration, clipping, loudness, loop seam
```
The melody lives in `PHRASES` at the top of the score section; edit it and re-run. **Honest limits:** I cannot listen to audio, so the checks above are numeric (every note is within 0.2 cents of its Hijaz pitch, the loop seam is smooth, nothing clips, loudness is steady); how it *sounds* is for your ears to judge. It is a convincing plucked-string simulation, not a real oud performance; a human oud player or composer would be a clear upgrade (the file drop-in below makes that a simple swap).

### Regenerating or extending the Blender art
The renders are procedural, so there are no `.blend` files to maintain.

```bash
python3 -m venv .venv-bpy
.venv-bpy/bin/pip install bpy          # Blender as a Python module (needs a matching Python; 5.2 wheel = Python 3.13)
SAMPLES=96 ONLY=dallah,chest .venv-bpy/bin/python tools/blender/make_art.py -- public/assets/art
```
Each prop is a function in `tools/blender/make_art.py`. Add a function, add it to the list at the bottom, run it. About 10 to 15 seconds per prop on CPU.

The 30 item icons come from `tools/blender/make_items.py` (one function per item id; same camera, light and palette for all, auto-framed so each icon fills its tile):

The six characters come from `tools/blender/make_characters.py` (ONLY=noura,tariq works the same way). The jury is a gold star medal with a ribbon, matching its star badge in the original art, not a person.

```bash
cd tools/blender
SAMPLES=64 SIZE=256 .venv-bpy/bin/python make_items.py -- ../../public/assets/art/items            # all 30
SAMPLES=64 SIZE=256 ONLY=qahwa_3,oud_5 .venv-bpy/bin/python make_items.py -- ../../public/assets/art/items  # just some
```

Limits: these are clean stylized 3D props, not painterly game-art. Some are simple (for example the agarwood chips and the paper filter) and are good candidates for an artist to redo. The character busts are deliberately toy-like (big heads, simple faces): that style is achievable procedurally, but it is not a replacement for a real character artist, and they have one pose and one expression each. For emotional poses, full-body art or a distinctive style you need an illustrator. Please also have someone from the community review the characters' clothing and headwear for cultural accuracy before launch.

## 2. Drop-in rules for art you provide

- **Format:** PNG with transparent background, 512x512 (square, object centered with ~8% padding). WebP is fine if you tell me.
- **Item icons** (already filled with Blender renders; replace any you like): one file per item id, `public/assets/art/items/<itemId>.png`.
  - Generators: `gen_qahwa`, `gen_barista`, `gen_sweets`, `gen_oud`
  - Chains (levels 1 to 6): `qahwa_1`..`qahwa_6`, `barista_1`..`barista_6`, `sweets_1`..`sweets_6`, `oud_1`..`oud_6`
  - Chests: `chest_1`, `chest_2`
  - Item names for each level are in `DOCUMENTATION.md` section 2.A.
- **Characters:** `public/assets/art/characters/<name>.png`, square bust portrait with a transparent background, centred with the face in the upper half (they are cropped to a circle): `noura`, `faisal`, `tariq`, `lama`, `sultan`, `ghabga` (the jury).
- Items in the same chain should share one light direction and one palette so the evolution reads at a glance.
- **Items need no code change:** `ItemArtwork` loads `public/assets/art/items/<itemId>.png` automatically, so replacing a file replaces the icon. If a file is missing the game falls back to the old SVG for that item only.
- **Characters need no code change either:** `CustomerPortrait` loads `public/assets/art/characters/<name>.png` (names: `noura`, `faisal`, `tariq`, `lama`, `sultan`, `ghabga`) and falls back to the SVG if a file is missing. The circle backdrop colours are in `PORTRAIT_BACKDROP` in `CompetitorModalsAndPortraits.tsx`.

## 3. Music and sound: what to ask for

- **Background loop:** 60 to 120 seconds, seamless loop, mp3 at 128 to 192 kbps (under about 2 MB). Calm Khaleeji or Hijaz-maqam oud with light percussion, no vocals.
- **Drop-in:** save it as `public/assets/audio/ambient.mp3` (replacing the generated one). The game loops it gaplessly and falls back to the built-in synth loop if the file is missing. Use a format browsers decode with sample-accurate looping (mp3 from a modern encoder, or ogg).
- **Stingers:** `order_complete.mp3` (about 2 to 3 s) and `level_up.mp3` (about 3 to 4 s) in the same folder replace the generated jingles.
- **Search terms:** "oud taqsim", "maqam hijaz", "khaleeji instrumental", "arabic lounge", "majlis ambience".
- **Optional later:** merge chimes per level (currently synthesized in code; I can wire in files).

## 4. Voice lines

**Status: recorded.** All 32 lines (about 1,070 Arabic characters, written in Saudi dialect: Najdi for Noura, Tariq and Sultan, Hijazi for Faisal, Riyadh youth for Lama, formal Arabic for the jury) are generated with ElevenLabs and stored in `public/assets/audio/voice/<id>.mp3` (ids like `noura_served_2`, 2.4 to 4.5 s, mono mp3, about 1.4 MB in total). The text is in `src/game/voiceLines.ts`. A character speaks when you serve one of their orders (normal or VIP line) and when their story chapter opens. Music ducks while they talk, and Mute silences voices too.

**Casting** (all Saudi-accent voices from the ElevenLabs library, model `eleven_v4`, no inline emotion tags, one take per line):

| Character | Voice |
| --- | --- |
| Grandmother Noura | Noorah - Saudi Warm & Clear (older Eastern Province woman) |
| Barista Faisal | Bandar (young, warm, friendly Saudi man) |
| Sheikh Tariq | Saleh - Saudi Arabic (lower-pitched storyteller) |
| Creator Lama | Nouf - Saudi Commercial & Documentary (young Saudi woman) |
| Sultan Al-Diriyah | Saadoun Professional Voice (deep, rich, authoritative Saudi man) |
| Festival jury | Ahmed, deep warm Modern Standard Arabic announcer |

Voice ids are in `tools/voice/voices.json`. To recast a character, change its `voice_id` there and run the generator with `--force --only <character>`.

**What was checked, and what was not.** Each file was transcribed back to text with ElevenLabs speech-to-text: all 32 match the intended words exactly (ignoring diacritics and punctuation), so nothing is misread, cut off or garbled. Files are trimmed of edge silence and set to the same loudness (-19.0 to -18.2 LUFS, peaks at most -2 dBFS), so no character is louder than another. **Nobody has listened to them yet.** Transcription cannot judge accent, dialect, emotion, pacing or whether a voice suits its character. Please listen to all 32 in the game, and have a native speaker of each dialect check the wording and delivery. Lines that sound wrong can be re-rolled for about 1 US cent each.

**How a line is played, in order:**
1. The recorded file `public/assets/audio/voice/<id>.mp3`.
2. If that file is missing, the phone's built-in Arabic voice, with a different pitch and pace per character.
3. If there is no Arabic voice either, silence. The game never reads Arabic with a non-Arabic voice.

**Regenerating or adding lines** (needs `ELEVENLABS_API_KEY` in your own shell; never paste keys into chat or commit them):
```bash
npm run voice:export                                    # refresh tools/voice/lines.json and docs/VOICE_LINES.md after editing voiceLines.ts
python3 tools/voice/generate_elevenlabs.py generate --dry-run
python3 tools/voice/generate_elevenlabs.py generate --only noura --limit 1
python3 tools/voice/generate_elevenlabs.py generate     # only lines whose text or voice changed are billed
```
`public/assets/audio/voice/manifest.json` records what each file was made from, so unchanged lines are skipped. `npm run voice:test` tests the generator against a local fake of the API (no key or network).

**Licensing, please check before shipping:**
- Every voice above is a shared **library** voice. ElevenLabs commercial rights depend on your plan, and each library voice has its own terms from its owner. Confirm your plan allows commercial use in a paid or ad-supported game, and read each voice's licence. If a voice is not cleared, recast it.
- Do not clone a real person's voice without written consent.

**Hiring a human actor instead:** send them `docs/VOICE_LINES.md` (file names, dialect, direction and English meanings per line) and ask for a written licence that covers game use and app-store distribution. Their files drop into the same folder with the same names.

## 6. Licence checklist before shipping
1. Keep a list of every third-party file with its source URL and licence.
2. CC-BY needs visible credit; add an in-app Credits screen if you use any.
3. Avoid "non-commercial" (CC-BY-NC) assets: not allowed in a paid or ad-supported app.
4. For anything made by a person, get a written licence or work-for-hire agreement that includes app-store distribution.
5. Do not use AI-generated or scraped images or music unless the tool's terms allow commercial use.
